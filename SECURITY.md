# Security

Word Counter crawls other people's websites, sometimes with credentials, and
keeps reports people share. If you find a way to read data you shouldn't, run
code on the server, misuse a crawl against a third party, or get credentials
out of it, please tell us privately first.

## Reporting

Use GitHub's private reporting: the **Security** tab of this repository, then
**Report a vulnerability**. Include the steps to reproduce it and what an
attacker could do with it.

Please don't open a public issue, and don't test against other people's data
on wordcount.wxrks.com: use your own account, or run the app locally.

We'll acknowledge a report within a few working days and tell you what we
decide to do about it.

## Supported versions

Only the current `main` branch, which is what runs at wordcount.wxrks.com.
